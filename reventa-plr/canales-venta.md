# Canales de venta

> Comisiones aproximadas; confirmar en la web de cada plataforma antes de fijar precio.

| Canal | Comisión aprox. | A favor | En contra |
|---|---|---|---|
| **Gumroad** | ~10 % + pasarela | Setup en minutos, sin web propia | Poco tráfico orgánico |
| **Payhip** | 0 % en plan gratuito (5 % según plan) | Barato, gestiona IVA UE | Marca poco conocida |
| **Etsy** | Tarifa por listing + ~6,5 % + pago | Tráfico de búsqueda real | Compite con packs de 1–3 € |
| **Amazon KDP** | 30/65 % según precio | Escaparate enorme | **Muchas licencias PLR lo prohíben** — verificar |
| **Hotmart** | ~10 % | Afiliados en español | Curva de aprendizaje |
| **Web propia + Stripe** | ~2 % pasarela | Margen máximo, lista propia | Tráfico 100 % tuyo |

## Recomendación de arranque
1. **Payhip** o **Gumroad** como tienda (rápido, sin coste fijo).
2. Tráfico desde contenido orgánico + lista de email.
3. Cuando haya ventas estables → web propia para quedarse el margen.

## Fiscal (España, verificar con asesor)
- Venta digital a consumidores UE → IVA del país del comprador. Payhip/Gumroad pueden gestionarlo; una web propia con Stripe, no.
- Ingresos recurrentes → alta en Hacienda (modelo 036/037) y posible autónomo.
